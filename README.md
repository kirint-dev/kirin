# LAB 10 Portfolio

Project structure follows the LAB 10 requirements:
- React + Vite + Bun
- Navbar
- Hero
- Skills
- Portfolio
- Number
- Footer
- react-icons
- react-parallax-tilt
- react-type-animation
- react-countup
- react-intersection-observer
- GitHub Pages deployment with gh-pages

## Run

```bash
bun install
bun dev
```

## Before deploying

Configured for GitHub repository: `https://github.com/kirint-dev/kirin`

Then run:

```bash
bun run deploy
```
